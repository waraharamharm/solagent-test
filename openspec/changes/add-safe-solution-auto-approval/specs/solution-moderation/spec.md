## ADDED Requirements

### Requirement: Автоодобрение выключено, пока не проверено в теневом режиме
Сервер SHALL записывать, какое решение он принял бы по каждой присланной записи, не
действуя, и SHALL одобрять автоматически только когда автоодобрение явно включено.

#### Scenario: Теневой режим
- **WHEN** приходит решение, а режим `shadow`
- **THEN** итог и причины записываются в лог
- **AND** решение остаётся `pending`, пока его не одобрит человек

### Requirement: Подходят только структурированные команды из белого списка
Решение SHALL подходить для автоодобрения, только если в нём есть структурированные
команды и каждая после разбора совпадает с белым списком.

#### Scenario: Команда с оператором оболочки
- **WHEN** команда содержит пайп, перенаправление, `;`, `&&`, `$(...)`, обратную кавычку или `sudo`
- **THEN** решение не подходит и ждёт человека

#### Scenario: Решение только со свободным текстом
- **WHEN** в решении нет структурированных команд
- **THEN** оно не подходит

### Requirement: Нужно независимое подтверждение
Решение SHALL одобряться автоматически, только когда одно и то же нормализованное
исправление прислали минимум три разных ключа, каждому из которых больше семи дней.

#### Scenario: Один ключ присылает одно и то же трижды
- **WHEN** все три записи пришли с одного ключа
- **THEN** число подтверждений равно одному и автоодобрения нет

### Requirement: Автоодобренные решения лежат в карантине и откатываются
Автоматически одобренное решение MUST быть помечено в результатах поиска, MUST попасть
в ежедневную сводку и SHALL отзываться вместе со всеми решениями с той же сигнатурой.

#### Scenario: Отзыв по сигнатуре
- **WHEN** оператор отзывает сигнатуру
- **THEN** все решения с этой сигнатурой пропадают из поиска
- **AND** эту сигнатуру больше никогда не одобряют автоматически

### Requirement: Вердикт модели не одобряет сам по себе
Проверка моделью MAY запретить или пометить решение и MUST NOT быть достаточной для
его одобрения.

#### Scenario: Модель считает риск низким
- **WHEN** модель сообщает низкий риск, но белый список или подтверждение не пройдены
- **THEN** решение не одобряется автоматически
